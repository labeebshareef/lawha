# LAWHA HIJABS — Premium Modest Fashion Website

> **Wear Your Crown**

A premium modest fashion brand website built with pure HTML5, CSS3, and vanilla JavaScript.

---

## Quick Start

1. Place your brand assets in the folders listed below
2. Open `index.html` in any modern browser
3. No build tools or frameworks needed

---

## Asset Placement Guide

| Folder | What to Place |
|---|---|
| `assets/logo/logo.png` | Brand logo (PNG, transparent bg, ~200px wide) |
| `assets/logo/favicon.png` | Favicon (32×32 or 64×64 PNG) |
| `assets/banners/hero-banner.jpg` | Homepage hero background (2000×1200px min) |
| `assets/banners/cta-banner.jpg` | CTA section background |
| `assets/banners/collections-banner.jpg` | Collections page hero |
| `assets/banners/about-banner.jpg` | About page hero |
| `assets/banners/contact-banner.jpg` | Contact page hero |
| `assets/models/model-1.jpg` to `model-4.jpg` | Model editorial photos (portrait, 800×1200px) |
| `assets/models/about-1.jpg`, `about-2.jpg` | About page lifestyle photos |
| `assets/models/insta-1.jpg`, `insta-3.jpg` | Instagram gallery (square, 600×600px) |
| `assets/products/product-1.jpg` to `product-8.jpg` | Product photos (portrait, 600×800px) |
| `assets/products/insta-2.jpg`, `insta-4.jpg` | Instagram gallery product shots |

## Project Structure

```
lawhahijabs/
├── index.html          # Homepage (9 sections)
├── collections.html    # Product grid with filters
├── about.html          # Brand story & philosophy
├── contact.html        # Contact form & WhatsApp
├── css/
│   ├── reset.css       # CSS reset
│   ├── variables.css   # Design tokens (colors, spacing, etc.)
│   ├── typography.css  # Fonts & text styles
│   ├── layout.css      # Grid system & utilities
│   ├── components.css  # All UI components
│   ├── animations.css  # Scroll & hover animations
│   └── responsive.css  # Mobile-first breakpoints
├── js/
│   ├── main.js              # Entry point
│   ├── scrollAnimations.js  # IntersectionObserver scroll fx
│   ├── navbar.js            # Sticky nav & hamburger menu
│   └── interactions.js      # Lazy loading, smooth scroll
└── assets/
    ├── logo/     ├── banners/
    ├── models/   ├── products/
    └── icons/
```

## Design System

- **Colors:** Warm earth tones (`--secondary: #7b4b2a`, `--accent: #d7a37b`)
- **Fonts:** Cormorant Garamond (headings) + DM Sans (body)
- **Animations:** IntersectionObserver-based scroll reveals, Apple-level subtle motion
- **Grid:** 12-column CSS Grid, responsive at 320/768/1024/1440px
